🎯 第一个月先做这三件

  • 饮料清零：可乐、奶茶、含糖饮料 → 无糖或白水。对脂肪肝和精力改善最直接。
  • 每天快走 30–40 分钟 + 晚餐主食减半。
  • 三餐规律、把早餐补上，每周一早上空腹称重。
💡 你有脂肪肝，最有效的就是「减重 + 控糖 + 规律运动」。建议先去做一次肝功能（ALT/AST）、血糖、血脂检查拿个基线。

🔄 爱吃的这样「换版本」

蛋糕/甜点 → 水果 + 无糖酸奶，偶尔一小块黑巧克力
油炸 / 肯德基 → 空气炸锅/烤制去皮鸡腿、烤鱼、凉拌菜
可乐 → 无糖可乐过渡 → 苏打水/茶
白米白面 → 糙米、燕麦、杂粮
奶茶 → 无糖茶、柠檬水
